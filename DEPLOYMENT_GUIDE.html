How The System Operates (The 30-Second Mental Model)

You are connecting two servers to work together seamlessly:

[ 🌐 HOSTINGER (Web Hosting) ] [ ⚡ VULTR (Cloud VPS) ] • Serves index.html + .htaccess • Runs streamer.py (Dual-chain: Robinhood + Arc) • Lightning-fast CDN with free SSL • Runs api_server.py (FastAPI on 127.0.0.1:8000) • Zero Python needed on Hostinger • Nginx SSL Reverse Proxy on Port 443 (api.yourdomain.com) │ │ └─────────── Fetches Live JSON via HTTPS ───────┘
💡
Why this is ideal: If your Vultr server is ever rebooting, the Hostinger dashboard will automatically display the embedded backup snapshot without showing any errors to your visitors!
1
Prepare Your 3 Required Values (Before Touching Servers)

1.1 Get Your Private RPC URLs

Public RPCs throttle and reject deep historical block logs. Obtain archive endpoints for both chains:

  • Robinhood Chain (4663): Log into QuickNode or Chainstack → create an endpoint for Robinhood Chain → copy the HTTPS URL.
  • Arc Chain (5042): Check the Arc Node Providers Directory or use your dedicated node endpoint → copy the HTTPS URL.

1.2 Choose Your 2 Domain Names

Decide which domain addresses you will use for the frontend and backend:

  • Frontend (Hostinger): e.g., https://tracker.yourdomain.com (or https://yourdomain.com)
  • Backend API (Vultr): e.g., https://api.yourdomain.com

1.3 Create Your DNS A Record

In your domain registrar (Namecheap, Cloudflare, GoDaddy, or Hostinger DNS):

Type: A
Host / Name: api
Points To / Value: [YOUR_VULTR_IPV4_ADDRESS]
TTL: Automatic (or 300 seconds)
⚠️
Make sure the DNS record has propagated (takes 2–10 minutes) before requesting SSL certificates with Certbot in Step 3. You can verify it using DNSChecker.org ↗.

3
Deploy The Vultr Backend Engine (Full Copy-Paste Commands)

3.1 Connect to Vultr via SSH

Log into your Vultr Dashboard, find your VPS IP, and run in PowerShell or Terminal:

ssh root@YOUR_VULTR_IP

3.2 Install System Packages & Clone Repo

Run this single block on your Vultr server:

sudo apt update && sudo apt install -y git python3 python3-venv nginx curl certbot python3-certbot-nginx
sudo git clone https://github.com/Jorence19/OmniReborn.git /opt/omnireborn
cd /opt/omnireborn
sudo bash deploy/install_vultr_backend.sh
ℹ️
Note: The installer script will create /etc/omnireborn.env and pause so you can enter your real RPCs.

3.3 Edit Your Environment File

Open the configuration file:

sudo nano /etc/omnireborn.env

Update these exact lines with your real RPCs, Etherscan API key, and domains:

ENABLED_CHAIN_IDS=4663,5042
ROBINHOOD_RPC_URL=https://YOUR_PRIVATE_ROBINHOOD_RPC
ARC_RPC_URL=https://YOUR_PRIVATE_ARC_RPC
ROBIN_ETHERSCAN_API_KEY=V3PFHFXJUWDH7AVUS26E9QUNTTTJ1QE5D4
API_ALLOWED_ORIGINS=https://tracker.yourdomain.com
API_ALLOWED_HOSTS=api.yourdomain.com,localhost,127.0.0.1
DASHBOARD_API_URL=https://api.yourdomain.com/api/candidates
💡
In nano editor: Press Ctrl + O, then Enter to save. Press Ctrl + X to exit.

3.4 Re-run the Installer & Setup Nginx with SSL

Run the installer to configure systemd services, then obtain your free SSL certificate:

cd /opt/omnireborn
sudo bash deploy/install_vultr_backend.sh

# Configure Nginx Reverse Proxy
sudo cp deploy/nginx-omnireborn-api.conf /etc/nginx/sites-available/omnireborn-api
sudo sed -i 's/api.example.com/api.yourdomain.com/g' /etc/nginx/sites-available/omnireborn-api
sudo ln -s /etc/nginx/sites-available/omnireborn-api /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

# Request Free SSL Certificate (replace with your real domain)
sudo certbot --nginx -d api.yourdomain.com

3.5 Run Deployment Health Preflight Checks

Run the automated sanity checks:

# Check Streamer Collector preflight (both 4663 and 5042)
sudo -u omnireborn /opt/omnireborn/.venv/bin/python /opt/omnireborn/streamer.py --preflight

# Check API Server readiness
sudo -u omnireborn /opt/omnireborn/.venv/bin/python /opt/omnireborn/api_server.py --check
✓
Both checks should output "ok": true across all categories with "ready": true.

3.6 Start the 24/7 Background Daemons

Activate your systemd services and watchdogs:

sudo systemctl enable --now omnireborn.service omnireborn-api.service omnireborn-watchdog.timer omnireborn-api-watchdog.timer omnireborn-backup.timer
sudo systemctl status omnireborn omnireborn-api
4
Deploy The Hostinger Frontend (2 Minutes)

4.1 Compile Dashboard with Your Live Vultr API

On your local Windows computer in PowerShell, run:

$env:DASHBOARD_API_URL = "https://api.yourdomain.com/api/candidates"
python generate_html_dashboard.py

This generates a production-ready index.html (186 KB) with your live API URL embedded.

4.2 Upload to Hostinger File Manager

Follow these simple clicks in Hostinger:

  1. Log into your Hostinger hPanel.
  2. Go to Websites → click Manage next to your site.
  3. Click File Manager → Navigate inside public_html/.
  4. Upload ONLY these TWO files:
    • index.html
    • .htaccess
⚠️
CRITICAL SECURITY RULE: Never upload forensics.db, .env, or Python scripts to Hostinger. The provided .htaccess automatically blocks unwanted file access.
